# Shopping Coplex

Premium fashion e-commerce storefront with:

- luxury home page and product presentation
- customizable apparel design studio
- login, profile dashboard, wishlist, saved designs, and order history
- shopping cart with coupon support and customization preview
- hidden admin login with product, order, user, coupon, and analytics panels
- Express backend scaffold ready for MongoDB integration
- done

## Frontend

```bash
npm install
npm run dev
```

## Backend

```bash
cd server
npm install
npm run dev
```
